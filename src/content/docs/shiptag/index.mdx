**A stunning, shareable SVG card for any repository.** Point it at `owner/repo`
and get back a polished card — the name, description, a colored language bar,
and star/fork counts — ready to drop into a README or serve as an Open Graph
social preview.

Every repo deserves a good first impression. GitHub's default social image is
generic; a hand-made banner goes stale the moment your stack changes. `shiptag`
renders the card from live data, so it's always current — and because it emits a
plain, self-contained SVG, it embeds anywhere and scales without blurring.

```sh
shiptag abdulmunimjemal/shiptag -o card.svg
```

![A shiptag social card for abdulmunimjemal/shiptag](https://raw.githubusercontent.com/abdulmunimjemal/shiptag/main/examples/shiptag.svg)

<CardGrid>
  <Card title="Two data sources" icon="github">
    Fetch live metadata from the GitHub REST API, or build a card **entirely
    offline** from a local checkout — no network, no token.
  </Card>
  <Card title="Pure, embeddable SVG" icon="document">
    The renderer is a pure function that returns a standalone `<svg>`. No native
    dependencies, no headless browser — it works in any README, page, or
    `og:image`.
  </Card>
  <Card title="Language bar, GitHub colors" icon="seti:default">
    The primary languages render as a rounded, color-coded bar with a legend,
    using the same canonical palette GitHub uses for its own language bars.
  </Card>
  <Card title="Themes & sizes" icon="setting">
    `dark` or `light`, and either the 1200×630 `og` social size or a compact
    `card`. Pick the combination that fits where it lands.
  </Card>
  <Card title="Optional AI summary" icon="sparkle">
    Pass `--summary` to replace the description with a one-line, punchy blurb
    from your own OpenAI-compatible endpoint. Off by default — no surprise API
    calls.
  </Card>
  <Card title="Zero config" icon="rocket">
    No config file, no setup. One command produces a card. Run it with `npx`
    without installing anything.
  </Card>
</CardGrid>

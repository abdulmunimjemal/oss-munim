**An instant, offline token + cost counter for LLM text.** Point it at a file,
pipe text in, or pass a handful of files — `tokcost` counts the tokens locally
and, on request, estimates what that input would cost.

Token counts drive both your context budget and your bill, but they're easy to
lose track of while iterating on a prompt. `tokcost` is a daily-use tool for
anyone building with LLMs: a fast, deterministic counter that runs entirely on
your machine — no network round-trip, no API key — and tells you exactly which
encoding it used.

```ansi
$ tokcost --cost -m gpt-4o prompt.md

  prompt.md   42 tokens

  total       42 tokens  (o200k_base)
  cost        $0.000105  (gpt-4o · $2.50 / 1M tokens)
```
